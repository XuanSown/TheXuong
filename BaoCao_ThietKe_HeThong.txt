4. THIET KE HE THONG

4.1 Thiet ke kien truc

   Mo hinh kien truc: MVC (Model - View - Controller)

   He thong TheXuong duoc xay dung theo mo hinh kien truc MVC ket hop voi Spring Boot Framework:

   - Model (Tang du lieu): Cac lop Entity (Products, Users, Orders...) anh xa truc tiep voi cac bang trong SQL Server thong qua JPA/Hibernate. Repository dam nhiem viec truy van CSDL.

   - View (Tang giao dien): Su dung Thymeleaf Template Engine de render giao dien HTML dong. Giao dien responsive ho tro hien thi tren ca PC va Mobile.

   - Controller (Tang dieu khien): Cac lop Controller nhan request tu nguoi dung, goi Service xu ly nghiep vu, tra ket qua ve View.

   Ngoai ra he thong con co:
   - Service Layer: Tang trung gian giua Controller va Repository, xu ly toan bo logic nghiep vu (tinh tien, kiem tra ton kho, ma hoa mat khau...).
   - Security Layer: Spring Security + JWT xu ly xac thuc va phan quyen (RBAC).
   - REST API Layer: Cung cap API cho Chatbot AI (n8n + Ollama Qwen2.5).

   Cong nghe su dung:

   STT | Thanh phan          | Cong nghe
   ----|---------------------|------------------------------------------
    1  | Ngon ngu            | Java 21
    2  | Framework           | Spring Boot 3.x
    3  | Template Engine     | Thymeleaf
    4  | CSDL                | Microsoft SQL Server
    5  | ORM                 | JPA / Hibernate
    6  | Bao mat             | Spring Security + BCrypt + JWT
    7  | Thanh toan          | VNPay Payment Gateway
    8  | Dang nhap xa hoi    | Google OAuth2
    9  | Build Tool          | Gradle
   10  | AI Chatbot          | Ollama (Qwen2.5:3B) + n8n + Telegram Bot
   11  | IDE                 | IntelliJ IDEA
